# 云 TTS 性价比独立复核（2026-09-16）

> **触发**：Owen 要求独立再调研云 TTS 有没有更具性价比的选择。
> **方法**：三路并行调研（中文厂商国际站 / 国际大厂+免费额度 / 开源自部署对照）＋ **本机裸 TCP 实测各端点 RTT** ＋ **亲自直读三家官方计费页**。
> **口径**：🟢一手核实（我亲自直读官方计费页或本机实测）　🟡单源二手　🔴未验证。
> **本报告推翻了原计划的默认档选择**，理由不是价格，是延迟。

---

## 0. 三句话结论

1. **"每万字符单价"这个判据是错的。** 在本项目用量下（≈24 万字符/月），单价差换算成绝对金额只有**每月十几块**，而**延迟差每句话都能感知**。
2. **真正的杠杆是免费额度。** Google Cloud TTS 与 Azure 的免费额度**直接覆盖本项目用量** → TTS 月成本可以是真的 **¥0**；这推翻了原计划"云优先 = 每月 ¥12–37"的成本前提。
3. **原默认档（阿里新加坡）应降级**：不是它贵，是**它慢**——实测稳定 **245ms**，而多数候选在 6ms 上下。

## 2. 三条改变决策的发现

### 2.1 免费额度才是真正的杠杆 🟢

- **Google Cloud TTS**（我直读官方价格页）：Chirp 3: HD 每月 **0–100 万字符免费**，超出 $30/1M；WaveNet/Standard **0–400 万字符免费**，超出 $4/1M。
- **Azure Speech**（我直读官方定价页）：F0 层 TTS **"0.5 million characters free per month"**。
- 本项目用量 ≈ **24 万字符/月** → **两家都完全覆盖，TTS 成本 = ¥0**。
- ⚠️ 免费额度按**计费账号**计，不是按项目。
- 🟢 官方明确：**CJK 只按字符数计，不按字节**（与 Fish Audio 的 UTF-8 字节计费不同，中文不会被 ×3）。

### 2.2 延迟把阿里新加坡踢出默认档 🟢（本机实测）

⚠️ **项目文档原记"阿里新加坡 176ms"——本次实测 245ms，以新测为准。**
⚠️ **TCP 到边缘 ≠ 推理在边缘**：GCP/Cloudflare 系是 anycast 前端，合成源站可能在别处；**只有 Azure northeurope 与 Polly eu-west-1 的计算实打实在爱尔兰**。本表是**下界**，端到端首包必须用真 key 复测。

### 2.3 克隆音色恰恰是大厂弱项 🟢

- AWS Polly：**无克隆**
- Google Instant Custom Voice：**$60/1M，且不提供免费额度**（官方价格页原文 "Not available"）
- Azure Custom Neural Voice：需审批，贵
- → **阿里 ¥0.01/音色仍是全球最便宜的克隆路径**，MiniMax ¥9.9 一次性次之。

**鱼与熊掌在这里分叉：要零成本选 Google/Azure（但没克隆），要克隆选阿里/MiniMax/Fish（但要付钱或接受慢/不稳）。**

## 4. 反直觉的负面结论（省得再找）

- 🟢 **"按秒计费更便宜"这条路不存在** —— 行业普遍按字符（唯一例外是 Azure 数字人）。
- 🟢 **无更便宜的选项**：在"无需大陆实名"的前提下，阿里国际 ¥0.8/万 已是最低；腾讯国际 ¥0.90/万、BytePlus ¥2.16/万 都更贵。**继续找更低价边际收益极低。**
- ⚠️ **口径陷阱**：Fish Audio 按 **UTF-8 字节**计费（中文 1 字 = 3 字节 → 实际中文单价 ×3）；BytePlus 按 M 字符。**直接对比会错 3 倍。**
- 与项目已有结论的关系：文档已算过 TTS 中档用量约 ¥10/月，**真正的成本中心是 CC 轮次（¥90–390/月等值），不是 TTS**。

## 5. 自部署对照（第三路调研）

- **M1 Pro 跑不动实时 TTS**：最好的 Apple Silicon 方案 RTF 也只有 **0.85×**（慢于实时）。真正的落点只有那台 5060 Ti。
- **2026-09 中文开源最强候选 = VoxCPM2**：唯一同时满足「Apache-2.0 **权重+代码**均明说可商用」「Seed-TTS-eval 中文 **CER 0.97**」「2B 单卡可跑（~8GB）」🟢。次席 Qwen3-TTS（官方 **97ms** 首包最亮眼）。
- 🔴 **许可陷阱**：**仓库 badge 是 Apache ≠ 权重可商用**。Fish S2-Pro、Higgs Audio V3、Breeze TTS 2 都是"代码开源 + 权重非商用"。IndexTTS-2.5 是 bilibili 自有许可且**强制 NVIDIA**。
- → **维持云优先不变**；把 **VoxCPM2 on 5060 Ti** 定为**断网兜底**的长期目标。
